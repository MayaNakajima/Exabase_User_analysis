## fix: チャット/Claude Code からの git 有効化（マウント制約の特定と対処）

- **原因特定**：作業フォルダのマウントは **rename 可・unlink 不可**。git は commit/merge 自体は成功するが、
  処理後の `*.lock`（index.lock 等）を削除できず残り、次の git が「`index.lock: File exists`」で停止していた。
  「tmp_obj を unlink できない」警告は無害（他リポジトリでも同様に出つつ成功）。真因は残留ロックのみ。
- **対処**：`tools/gitsafe.sh` を追加。git 実行前に残留 `*.lock` を `.git/_locktrash/` へ退避(rename)してから git を実行。
  併せて `gc.auto=0` / `maintenance.auto=false` に設定し stuck lock の発生源を抑止。
- `docs/引き継ぎ書.md` の Git 章を「チャット/Claude Code での git 開発（gitsafe 前提）」に更新。
- `main` に初回コミット `b9ca91f` を作成（本フォルダのマウント上で commit が通ることを実証）。
- 以降の開発は **Claude Code** で継続。push は従来どおりお手元（GitHub Desktop）。
